# 📊 E-Commerce Sales Analysis | SQL & Power BI

## 📌 Project Overview

This project analyzes e-commerce sales data using **MySQL and Power BI** to understand sales performance, customer behavior, product performance, order trends, and other key business metrics.

The project includes **34 SQL queries** and an interactive **Power BI dashboard** designed to convert raw sales data into meaningful business insights.
